# E02-I：自动化缺口
**PARTIAL。** 从已可信的 FAIL 到一个可执行、可复核、可拒绝的局部编辑已验证；从任意图纸到可信 FAIL 尚未自动化。

| 环节 | 当前自动化 | 仍需外部证据 |
|---|---|---|
| Public Drawing → Candidate | 只读公开图的内容/哈希绑定 | 现有VLM可提标签、ROI、多视图和歧义，不可自签真实性 |
| View Alignment | 给定坐标可确定性生成OCC可见/隐藏投影；配准绑定产物 | 视图方向、独立锚点、镜像/尺度和非对称特征对应仍需独立复核 |
| Evidence Validation | 校验签发清单、来源、SHA和允许的判定域 | 投影线语义、标注的指向和图纸解读仍人工签发；22 mm为反例 |
| Geometry Constraint | 确定性HLR、截线、有限尺寸、唯一阶段变化可测 | 缺身份、多个映射、框架不明或信号互相矛盾→UNKNOWN |
| Local Repair | 受限副本事务、固定操作、保全基线、重算/重开/几何差分 | 通用安全操作与依赖判据、拓扑重命名和副作用阈值需跨题验证 |

跨任务最小方案：先选少量公开图纸中有独立视图锚点的任务，VLM只出带证据框的候选，再由独立审查签发坐标和约束；复用通用观察谓词，不复用本题Z=28、特征名和ROI。用相同夹具类型验“歧义→UNKNOWN”，报告证据覆盖率、人工复核成本、错误定位率和保全通过率。冻结签发与产物哈希，后续才评估模型能否缩小人工复核量。不做OCR训练，不从评分器推断目标，不把本题人工清单写入正式Agent。
