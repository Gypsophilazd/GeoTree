# Windows + WSL2

Configure WSL2 Ubuntu with Python 3.12 and uv, and enable Docker Desktop's Ubuntu integration. In Ubuntu change to your clone (for a Windows clone use wslpath to translate its path). Follow the README commands. For bind-mount permission problems on a Windows volume, use a clone on the Ubuntu filesystem, or set GEOTREE_STUDIO_RUN_DIR to an absolute directory in that filesystem. The model-free smoke checks Mock, real FreeCAD, the bounded repair and mesh export. The optional Windows Codex bridge needs your own login. Keep the service on loopback; remote use requires a private SSH port forward.
